Bug Bully includes Fairy-Stockfish WASM 1.1.12 and the Crazyhouse NNUE network from the official Fairy-Stockfish network list.

Engine source: https://github.com/ianfab/fairy-stockfish.wasm
Engine license and authorship: see Copying.txt and AUTHORS in this folder.
Network source: https://fairy-stockfish.github.io/nnue/

The engine is run locally in the browser. Bug Bully sends no position data to a remote analysis service.
